# Agenda de contatos

Aplicação em Python, feita individualmente, para cadastrar, listar, buscar e remover contatos via terminal.

## Funcionalidades

- Cadastrar um novo contato (nome, telefone e email)
- Listar todos os contatos cadastrados
- Buscar um contato pelo nome
- Remover um contato

## Como executar

```
python agenda.py
```
